# English Learning Telegram Bot

Telegram-бот для изучения английского языка с карточками, тестами, статистикой и избранными словами.

## Что умеет сейчас

- отвечает на команду `/start`;
- показывает удобную клавиатуру с основными действиями;
- выдаёт случайные карточки с английскими словами и переводами;
- позволяет добавлять слова в избранное с помощью inline-кнопки;
- показывает список избранных слов конкретного пользователя;
- проводит тесты на перевод английских слов;
- принимает несколько правильных вариантов перевода;
- показывает другие возможные переводы после правильного ответа;
- сообщает правильные варианты, если ответ неверный;
- сохраняет статистику прохождения тестов;
- позволяет сбрасывать статистику пользователя;
- показывает пользователю личную статистику;
- хранит пользователей и их данные в SQLite;
- ведёт логирование работы бота в файл и терминал.

## Что планируется

- игра на сопоставление английского слова и перевода;
- система повторения слов;
- повторение слов, на которых пользователь чаще ошибается;
- уровни сложности;
- улучшение системы проверки ответов;
- расширение и улучшение словаря.

## Технологии

- Python
- aiogram 3
- Telegram Bot API
- SQLite
- logging

## Установка

Клонируй репозиторий:

```bash
git clone https://github.com/eusobai/FlashLearn.git
cd FlashLearn
```

Создай виртуальное окружение:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Установи зависимости:

```powershell
py -m pip install -r requirements.txt
```

## Настройка токена

Создай файл `.env` в корне проекта:

```env
BOT_TOKEN=твой_токен_от_BotFather
```

Никогда не загружай `.env` в GitHub.

Файл `.env` должен быть добавлен в `.gitignore`.

## Словарь

Слова для карточек и тестов хранятся в файле:

```text
words.json
```

Формат записи:

```json
{
  "english": "factory",
  "russian": "завод, фабрика"
}
```

Если у слова несколько переводов, бот принимает любой из них как правильный ответ.

## Избранные слова

Пользователь может добавить слово в избранное с помощью кнопки:

```text
⭐ Добавить в избранное
```

Избранные слова сохраняются отдельно для каждого пользователя.

Пользователь может открыть раздел:

```text
⭐ Избранные слова
```

и получить список сохранённых слов и их переводов.

## База данных

SQLite используется для хранения данных пользователей.

В базе используются следующие таблицы:

- `users` — пользователи бота;
- `user_stats` — статистика пользователей;
- `favourite_word` — избранные слова пользователей.

В статистике сохраняются:

- количество правильных ответов;
- общее количество попыток;
- точность ответов.

Избранные слова сохраняются вместе с:

- `user_id`;
- английским словом;
- переводом.

## Запуск

```powershell
py main.py
```

После запуска в терминале появится сообщение:

```text
Бот запустился
```

После этого открой Telegram, найди своего бота и отправь:

```text
/start
```

## Основные команды

```text
/start       — запустить бота
/card        — получить случайную карточку
/quiz        — пройти тест
/stats       — посмотреть статистику
/reset_stats — сбросить статистику
/favourites  — посмотреть избранные слова
```

Также основные действия доступны через клавиатуру бота.
