# FlashLearn --- English Learning Telegram Bot

Telegram-бот для изучения английского языка. FlashLearn помогает учить
английские слова с помощью карточек, тренировок.

## Возможности

-   Получение случайной карточки английского слова.
-   Просмотр перевода, определения, примера и произношения.
-   Добавление слов в избранное.
-   Просмотр сохранённых слов и удаление отдельных слов.
-   Текстовая тренировка: пользователь самостоятельно вводит перевод.
-   Тренировка с вариантами ответа.
-   Проверка нескольких допустимых переводов одного слова.
-   Завершение текстовой и тестовой тренировки кнопкой «🛑 Завершить
    тренировку».
-   Подсчёт правильных ответов, общего количества попыток и точности
    текущей тренировки.
-   Логирование событий и ошибок.

> **Текущий статус:** кнопка «Тренировка моих слов» уже запускает вопрос
> из избранного. Непрерывная тренировка избранных слов, её отдельная
> статистика и завершение такой тренировки пока требуют доработки.

## Главное меню

-   📚 Учить слова
-   🧠 Тренировка
-   📊 Моя статистика
-   ⭐ Мои слова
-   ❓ Помощь

В разделе «Мои слова» можно просмотреть сохранённые слова и удалить
ненужные. В карточке слова есть кнопка добавления в избранное.

## Команды

  Команда          Назначение
  ---------------- ---------------------------------------
  `/start`         Запустить бота и открыть главное меню
  `/card`          Получить случайную карточку слова
  `/quiz`          Выбрать режим тренировки
  `/stats`         Посмотреть накопленную статистику
  `/reset_stats`   Сбросить статистику
  `/favourites`    Посмотреть сохранённые слова
  `/help`          Показать справку

## Режимы тренировки

### Текстовый ответ

Бот показывает английское слово, пользователь пишет перевод. Ответ
проверяется без учёта регистра и пробелов по краям. Если у слова указано
несколько переводов через `;`, каждый из них принимается.

Тренировка продолжается до нажатия кнопки «🛑 Завершить тренировку».

### Выбор ответа

Бот показывает английское слово и четыре варианта перевода: один
правильный и три неправильных. Варианты перемешиваются. После ответа бот
сообщает результат и предлагает следующий вопрос.

Тренировка продолжается до нажатия кнопки «🛑 Завершить тренировку».

### Тренировка избранных слов

Из списка «Мои слова» можно запустить тренировку сохранённых слов. На
текущем этапе обработчик выбирает одно случайное слово из избранного и
показывает вопрос. Полный цикл с повторными вопросами и итоговой
статистикой ещё находится в разработке.

## Статистика

Временная статистика текущей тренировки хранится в памяти приложения и
включает:

-   количество отвеченных вопросов;
-   количество правильных ответов;
-   тип тренировки.

После завершения текстовой или тренировочной с выбором ответа бот
показывает итог и процент точности.

Накопленная статистика хранится в таблице `user_stats` в PostgreSQL и
обновляется после каждого ответа. Команда `/stats` показывает общие
результаты, а `/reset_stats` обнуляет их.

### `main.py`

Основная логика Telegram-бота: команды и обработчики, клавиатуры,
карточки, тренировки, проверка ответов, избранные слова, статистика и
логирование.

### `database.py`

Функции доступа к PostgreSQL: подключение, получение слов, добавление
пользователей, чтение и обновление статистики,
добавление/получение/удаление избранных слов.

## База данных

Проект использует PostgreSQL. В текущей схеме задействованы следующие
таблицы:

``` text
users
user_stats
favourite_words
topics
levels
parts_of_speech
words
```

### `users`

``` text
user_id
```

### `user_stats`

``` text
user_id
correct
total
```

### `favourite_words`

``` text
id
user_id
word_id
```

Для предотвращения повторного сохранения одной и той же пары
пользователя и слова используется ограничение:

``` text
UNIQUE(user_id, word_id)
```

### `words`

``` text
id
english
russian
definition
example
topic_id
level_id
part_of_speech_id
pronunciation
created_at
```

Справочные таблицы `topics`, `levels` и `parts_of_speech` связывают
слова с темами, уровнями и частями речи. Уровни словаря: `A1`, `A2`,
`B1`, `B2`, `C1`, `C2`.

## Несколько допустимых переводов

Переводы одного слова хранятся в поле `russian` через точку с запятой,
например:

``` text
причина; довод
```

При проверке строка разделяется на отдельные варианты, пробелы по краям
удаляются, а регистр приводится к нижнему. Пользователь может ввести
любой из указанных вариантов.

## Переменные окружения

Секреты не хранятся в Git. Создайте файл `.env` на основе `.env.example`
и укажите:

``` env
BOT_TOKEN=your_bot_token_here
DATABASE_URL=your_database_url_here
```

Не публикуйте реальные токены, пароли или строки подключения в GitHub.

## Установка и запуск

Клонируйте репозиторий:

``` bash
git clone https://github.com/eusobai/FlashLearn.git
cd FlashLearn
```

Создайте виртуальное окружение:

``` bash
python -m venv .venv
```

Активируйте его в Windows:

``` powershell
.venv\Scripts\activate
```

Установите зависимости:

``` bash
pip install -r requirements.txt
```

Создайте `.env`, заполните `BOT_TOKEN` и `DATABASE_URL`, затем
запустите:

``` bash
python main.py
```

Для работы нужны доступный Telegram Bot Token и настроенная
PostgreSQL-база с ожидаемыми таблицами.

## Логирование

Логи записываются в файл:

``` text
logs/bot.log
```

Также сообщения логирования выводятся в консоль. Пример записи:

``` text
Quiz answered | user_id=... | correct=True
```
