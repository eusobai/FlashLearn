# English Learning Telegram Bot

Telegram-бот для изучения английского языка с карточками, тестами.

## Что умеет сейчас

- отвечает на команду `/start`;
- показывает клавиатуру с основными действиями;
- выдаёт случайные карточки английских слов;
- показывает перевод, определение, пример и произношение слова;
- позволяет добавлять слова в избранное с помощью inline-кнопки;
- показывает список избранных слов конкретного пользователя;
- проводит тесты на перевод английских слов;
- принимает несколько правильных вариантов перевода;
- показывает другие возможные переводы после правильного ответа;
- сообщает правильные варианты, если ответ неверный;
- сохраняет статистику прохождения тестов;
- позволяет сбрасывать статистику пользователя;
- показывает личную статистику пользователя;
- хранит данные пользователей, статистику и избранные слова в PostgreSQL;
- хранит словарь в PostgreSQL;
- ведёт логирование работы бота в файл и терминал;
- предоставляет команды Telegram для основных функций бота.

## Что планируется

- игра на сопоставление английского слова и перевода;
- система повторения слов;
- повторение слов, на которых пользователь чаще ошибается;
- использование уровней сложности при изучении слов;
- улучшение системы проверки ответов;
- расширение и улучшение словаря;
- развитие системы работы с темами и уровнями слов.

## Установка

Клонируй репозиторий:

```bash
git clone https://github.com/eusobai/FlashLearn.git
cd FlashLearn
```

Создай виртуальное окружение:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Установи зависимости:

```powershell
py -m pip install -r requirements.txt
```

## Настройка

Создай файл `.env` в корне проекта:

```env
BOT_TOKEN=твой_токен_от_BotFather
DATABASE_URL=твоя_строка_подключения_к_PostgreSQL
```

`DATABASE_URL` используется для подключения к PostgreSQL.

Не публикуй `.env` и не загружай его в GitHub.

Файл `.env` должен находиться в `.gitignore`.

Для примера переменных окружения используется файл `.env.example`.

## Словарь

Словарь больше не хранится в `words.json`.

Слова хранятся в PostgreSQL в таблице `words`.

Каждое слово содержит:

- английское слово;
- перевод;
- определение;
- пример использования;
- произношение;
- тему;
- уровень сложности;
- часть речи;
- дату создания.

Для организации слов используются таблицы:

- `topics` — темы слов;
- `levels` — уровни сложности;
- `parts_of_speech` — части речи;
- `words` — сами слова.

## Избранные слова

Пользователь может добавить слово в избранное с помощью inline-кнопки:

```text
⭐ Добавить в избранное
```

Избранные слова сохраняются отдельно для каждого пользователя.

Для этого используется таблица `favourite_words`, которая связывает пользователя со словом через:

- `user_id` — ID пользователя;
- `word_id` — ID слова.

Одно и то же слово нельзя добавить в избранное одному пользователю несколько раз.

## База данных

Для хранения данных используется PostgreSQL, размещённый в Supabase.

В базе используются следующие таблицы:

- `users` — пользователи бота;
- `user_stats` — статистика пользователей;
- `favourite_words` — избранные слова пользователей;
- `words` — словарь;
- `topics` — темы слов;
- `levels` — уровни сложности;
- `parts_of_speech` — части речи.

### Статистика

В таблице `user_stats` сохраняются:

- количество правильных ответов;
- общее количество попыток.

На основе этих данных бот рассчитывает точность ответов.

### Связи между таблицами

```text
users
  │
  │ user_id
  ↓
favourite_words
  │
  │ word_id
  ↓
words
```

Таблицы `words` также связаны с таблицами тем, уровней и частей речи.

Подключение к PostgreSQL выполняется через `psycopg2` с использованием переменной окружения `DATABASE_URL`.

## Запуск

```powershell
py main.py
```

После запуска открой Telegram, найди своего бота и отправь:

```text
/start
```

## Основные команды

```text
/start       — запустить бота
/card        — получить случайную карточку
/quiz        — пройти тест
/stats       — посмотреть статистику
/reset_stats — сбросить статистику
/favourites  — посмотреть избранные слова
/help        — открыть справку
```

Основные действия также доступны через клавиатуру бота.
