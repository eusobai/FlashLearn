# FlashLearn — English Learning Telegram Bot

Telegram-бот для изучения английского языка. FlashLearn помогает учить английские слова с помощью карточек, текстовых тренировок и тестов с вариантами ответа.

## Возможности

- Получение случайной карточки английского слова.
- Просмотр перевода, определения, примера и произношения.
- Добавление слов в избранное.
- Просмотр сохранённых слов.
- Удаление отдельных слов из избранного.
- Текстовая тренировка: пользователь самостоятельно вводит перевод.
- Тренировка с вариантами ответа.
- Отдельная тренировка избранных слов.
- Непрерывное прохождение тренировки избранных слов.
- Проверка нескольких допустимых переводов одного слова.
- Завершение тренировки кнопкой «🛑 Завершить тренировку».
- Подсчёт правильных ответов, общего количества попыток и точности.
- Накопление общей статистики пользователя.
- Логирование событий и ошибок.

## Главное меню

- 📚 Учить слова
- 🧠 Тренировка
- 📊 Моя статистика
- ⭐ Мои слова
- ❓ Помощь

В разделе «Мои слова» пользователь может просматривать сохранённые слова, удалять их и запускать тренировку по избранным словам.

В карточке слова есть кнопка:

`⭐ Добавить в мои слова`

## Команды

| Команда | Назначение |
|---|---|
| `/start` | Запустить бота и открыть главное меню |
| `/card` | Получить случайную карточку слова |
| `/quiz` | Выбрать режим тренировки |
| `/stats` | Посмотреть накопленную статистику |
| `/reset_stats` | Сбросить статистику |
| `/favourites` | Посмотреть сохранённые слова |
| `/help` | Показать справку |

## Режимы тренировки

### Текстовый ответ

Бот показывает английское слово, после чего пользователь самостоятельно вводит перевод.

Ответ проверяется:

- без учёта регистра;
- без учёта пробелов по краям;
- с поддержкой нескольких допустимых переводов.

Если у слова указано несколько переводов через `;`, каждый из них считается правильным.

Например:

```text
причина; довод
```

Пользователь может ввести любой из этих вариантов.

Тренировка продолжается до нажатия кнопки:

`🛑 Завершить тренировку`

### Выбор ответа

Бот показывает английское слово и варианты перевода.

Для обычной тренировки:

- выбирается одно правильное слово;
- добавляются неправильные варианты;
- варианты перемешиваются;
- пользователь выбирает ответ с помощью inline-кнопки;
- бот сразу сообщает результат;
- после ответа автоматически отправляется следующий вопрос.

Тренировка продолжается до нажатия:

`🛑 Завершить тренировку`

### Тренировка избранных слов

Пользователь может запустить отдельную тренировку по словам, которые были добавлены в ⭐ избранное.

Для запуска тренировки с вариантами необходимо минимум **2 избранных слова**.

Вопрос формируется только из списка избранных слов.

Например:

```text
⭐ Избранные слова

apple
dog
building
book
```

При тренировке:

```text
Вопрос 1 → ⭐ избранные слова
Вопрос 2 → ⭐ избранные слова
Вопрос 3 → ⭐ избранные слова
...
```

После каждого ответа следующий вопрос снова выбирается из избранных слов.

Таким образом, тренировка избранных слов не переключается на общий список `WORDS`.

Для обычной тренировки и тренировки избранных слов используются отдельные режимы:

```text
choice
favourite_choice
```

Это позволяет боту понимать, из какого набора слов нужно формировать следующий вопрос.

## Статистика

Во время текущей тренировки статистика хранится в памяти приложения.

Она включает:

- количество правильных ответов;
- общее количество вопросов;
- тип текущей тренировки.

Например:

```text
correct = 7
total = 10
type = "choice"
```

После каждого ответа накопленная статистика пользователя обновляется в PostgreSQL.

Общую статистику можно посмотреть через:

`/stats`

Статистику можно сбросить через:

`/reset_stats`

Текущий тип тренировки также учитывается при переходе к следующему вопросу.

Например:

```text
type = "choice"
        ↓
следующий вопрос из WORDS
```

или:

```text
type = "favourite_choice"
        ↓
следующий вопрос из favourite_words
```

## База данных

Проект использует PostgreSQL.

В текущей схеме используются следующие таблицы:

```text
users
user_stats
favourite_words
topics
levels
parts_of_speech
words
```

### `users`

```text
user_id
```

Используется для хранения пользователей Telegram-бота.

### `user_stats`

```text
user_id
correct
total
```

Хранит накопленную статистику пользователя.

### `favourite_words`

```text
id
user_id
word_id
```

Связывает пользователя с сохранёнными словами.

Для предотвращения повторного добавления одного и того же слова используется ограничение:

```sql
UNIQUE(user_id, word_id)
```

### `words`

```text
id
english
russian
definition
example
topic_id
level_id
part_of_speech_id
pronunciation
created_at
```

Слова связаны со справочными таблицами тем, уровней и частей речи.

Уровни словаря:

```text
A1
A2
B1
B2
C1
C2
```

## Получение избранных слов

Избранные слова получаются через `JOIN` между `favourite_words` и `words`.

Используется примерно такой запрос:

```sql
SELECT
    words.id,
    words.english,
    words.russian,
    words.definition,
    words.example,
    words.pronunciation
FROM favourite_words
JOIN words
    ON favourite_words.word_id = words.id
WHERE favourite_words.user_id = %s
```

Благодаря этому избранные слова возвращаются в той же структуре, что и обычные слова из `WORDS`.

Например:

```python
{
    "id": 5,
    "english": "apple",
    "russian": "яблоко",
    "definition": "...",
    "example": "...",
    "pronunciation": "..."
}
```

Это позволяет использовать одинаковую логику проверки `id` как для обычной тренировки, так и для тренировки избранных слов.

## Несколько допустимых переводов

Переводы одного слова хранятся в поле `russian` через точку с запятой.

Например:

```text
причина; довод
```

При проверке ответа строка разделяется на отдельные варианты.

Каждый вариант:

- очищается от пробелов по краям;
- переводится в нижний регистр;
- сравнивается с ответом пользователя.

Поэтому оба варианта считаются правильными:

```text
Причина
```

и:

```text
довод
```

## Установка и запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/eusobai/FlashLearn.git
cd FlashLearn
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его в Windows:

```powershell
.venv\Scripts\activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Создайте `.env` и заполните:

```env
BOT_TOKEN=your_bot_token_here
DATABASE_URL=your_database_url_here
```

Запустите бота:

```bash
python main.py
```

Для работы необходимы:

- Telegram Bot Token;
- доступная PostgreSQL-база данных;
- настроенная структура базы данных.

## Логирование

Логи записываются в:

```text
logs/bot.log
```

Также сообщения логирования выводятся в консоль.

Пример:

```text
Choice quiz started | user_id=...
```

или:

```text
Choice quiz answered | user_id=... | correct=True
```

Логирование используется для отслеживания запуска тренировок, ответов пользователей и ошибок.
